# WorldNewsUSUA — автоматическая публикация новостей

Готовый бесплатный RSS-бот для Telegram-канала **@WorldnewsUSUA**.  
OpenAI API не используется и дополнительных расходов OpenAI нет.

## Сначала: отзовите раскрытый токен

Токен, отправленный в переписку, необходимо считать скомпрометированным.

1. Откройте **@BotFather**.
2. Нажмите `/mybots`.
3. Выберите **@WorldNewsEditorbot**.
4. Откройте **API Token**.
5. Нажмите **Revoke current token** / отозвать текущий токен.
6. Получите новый токен.
7. Новый токен больше не отправляйте в чат и не записывайте в файлы проекта.

Отзыв старого токена обязателен. Удаление сообщения из чата само по себе недостаточно.

## Что делает проект

- проверяет RSS-источники каждые 15 минут;
- публикует максимум 3 наиболее приоритетные новости за запуск;
- добавляет заголовок, краткое RSS-описание, источник и ссылку;
- использует изображение из RSS, когда оно доступно;
- удаляет повторы по ссылке и похожим заголовкам;
- приоритизирует срочные события, Украину, Германию, США, ЕС, экономику и технологии;
- исключает часть спорта, гороскопов, рекламы и светской хроники;
- не копирует полный текст статей;
- не использует OpenAI API.

Тексты остаются на языке конкретного RSS-источника. Автоматического качественного перевода без отдельного переводческого API здесь нет.

## Установка на GitHub

### 1. Создайте репозиторий

На GitHub нажмите:

**New repository → Repository name:** `worldnews-telegram-bot`

Для бесплатных запусков GitHub Actions удобнее выбрать **Public**. Код будет публичным, но токен хранится отдельно в зашифрованном Secret и в код не попадает.

Загрузите в репозиторий всё содержимое этого архива, включая скрытую папку `.github`.

### 2. Добавьте новый токен как Secret

В репозитории откройте:

**Settings → Secrets and variables → Actions → New repository secret**

Заполните:

- **Name:** `TELEGRAM_BOT_TOKEN`
- **Secret:** новый токен от BotFather

Нажмите **Add secret**.

Не создавайте обычную переменную с токеном. Нужен именно **Repository secret**.

### 3. Разрешите workflow сохранять список опубликованных новостей

Откройте:

**Settings → Actions → General → Workflow permissions**

Выберите:

**Read and write permissions**

Сохраните.

### 4. Проверьте права бота в Telegram

В канале **@WorldnewsUSUA** бот **@WorldNewsEditorbot** должен быть администратором с правами:

- публикация сообщений;
- редактирование сообщений — желательно;
- удаление сообщений — желательно.

### 5. Отправьте тестовый пост

Откройте вкладку **Actions** в репозитории.

Выберите workflow **World News Publisher** → **Run workflow**:

- mode: `test`

Нажмите **Run workflow**. В канале должно появиться сообщение:

`WorldNewsUSUA: тест успешен`

### 6. Запустите сбор новостей вручную

Повторите запуск, но выберите:

- mode: `run`

После проверки workflow будет запускаться автоматически в минуты:

`07, 22, 37 и 52` каждого часа.

Это интервал 15 минут, специально сдвинутый от начала часа, когда GitHub Actions чаще задерживает задания.

## Настройка

Главные параметры находятся в `config.yaml`.

### Ограничить число публикаций

```yaml
max_posts_per_run: 3
```

### Отключить источник

```yaml
enabled: false
```

### Добавить RSS

Добавьте в `sources`:

```yaml
- name: Название источника
  url: https://example.com/rss.xml
  weight: 2
  enabled: true
```

### Изменить тематику

- `priority_keywords` — повышает приоритет новости;
- `exclude_keywords` — исключает материал;
- `hashtag_rules` — назначает хэштеги.

## Ограничения

1. GitHub не гарантирует запуск ровно до секунды; иногда расписание задерживается.
2. Если RSS-источник меняет адрес или блокирует запросы, он временно перестанет работать.
3. Без ИИ бот не проверяет фактическую достоверность статьи и не пишет собственный пересказ.
4. Перед публичным использованием учитывайте правила и условия каждого RSS-источника.
5. Не публикуйте токен в Issues, Actions logs, файлах или сообщениях.

## Безопасность

В проекте нет токена. Он читается только из:

```text
secrets.TELEGRAM_BOT_TOKEN
```

Если токен снова раскроется, немедленно отзовите его через BotFather и замените значение Secret.
